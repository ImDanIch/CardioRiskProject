# Етап 5. Інтерактивне прогнозування

Режим `interactive` приймає 11 характеристик людини з клавіатури та
використовує **вже навчену** модель `models/cardio_final_model.joblib`.
Повторне навчання не потрібне. Дані перевіряються правилами
`DataPreprocessor.validate_prediction_data()`; вік користувач вводить
у повних роках, але для конвеєра він переводиться в дні.

```powershell
python main.py interactive
```

Для явного локального збереження вхідних даних і прогнозів у CSV:

```powershell
python main.py interactive --output results/tables/manual_predictions.csv
```

Без `--output` введені дані **не зберігаються**. Файл із результатами не
слід публікувати в GitHub. Режим дозволяє послідовно вводити кількох людей;
вихід — `н`, Enter або Ctrl+C. Перевірка коректності чисел і категорій
виконується до виклику `RiskPredictor.predict`.

Програма виводить ймовірність **класу `cardio=1`**, рішення за порогом 0,40
(поріг береться з файлу моделі) та попередження щодо обмежень.
Це класифікація позначки `cardio` у навчальному датасеті, а не медичний
діагноз і не розрахунок ризику серцево-судинної події за 5 чи 10 років.

Перевірка:

```powershell
python -m pytest -q
python main.py interactive
```

Структура: `src/interactive_prediction.py` — збір, валідація, відображення;
`src/predictor.py` — завантаження моделі та прогноз; `main.py` — CLI-команда.
